# AgentReady Documentation Directory

Welcome to the AgentReady developer documentation. Below is a directory of guides to help you navigate, build, and deploy the system:

1. **[Technical Handoff & Implementation Context](implementation-context.md)**: Details the monorepo module layout, completed core features, DB schemas, API endpoints, and test coverage mapping.
2. **[Technical Reference Document](technical-reference.md)**: Reference guide with exact, verbatim code blocks for core Prisma schemas, machine authentication hooks, executions/traces routes, and approval gate matching rules.
3. **[Production Deployment Guide](deployment-ready.md)**: A step-by-step checklist on configuring environment variables, running production migrations, and launching services.
4. **[Local Setup & Troubleshooting Guide](known-setup-issues.md)**: Documented resolutions for common environmental constraints (e.g. running tests without Docker, Prisma generation hooks, and port configurations).
5. **[Product & Design Interview Guide](interview-guide.md)**: Conceptual specifications, user flows, and product decisions governing the AgentReady platform.
